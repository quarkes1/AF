## 文件与接入约束

- `bgm/`：六首已审核的 48 kHz 双声道 MP3 曲目；三首已否决的 OGG 只留本地并受 Git 忽略。
  `sfx/`：五种已审核的 44.1 kHz 双声道 OGG 操作音效。
- `brand/`：两段 44.1 kHz 单声道开屏名称朗读，每次启动等概率随机选择一版。
- `manifest.json`：音频规则、用途及候选信息；`candidates[].proposedFile` 只用于预览。
  五种音效、主页、日常、学习、情绪与突破曲已按用户选择登记；不得启用已否决候选。
- `provenance.json`：谱面、渲染工具与音色来源、许可、SHA-256 和实际解码检查结果。
- `scores/`：本地忽略的已否决候选音符事件源和 MIDI，不随仓库交付。
- `licenses/`：保留音色库的原始许可；不随应用分发整个音色库或离线合成工具。

BGM 候选循环区间按实际解码帧数记录，采用前一轮演奏的释放尾音、循环式房间延迟
以及极短边界包络。已检查有限值、削波、解码帧数及边界跳变；这些不能证明听感无缝。
循环试听与音乐性判断仍需要人工完成。短音效的容器标称时长和实际解码时长分别记录，
以播放器实际解码结果为准。不要只凭扩展名或容器时长设置循环。

沿用规格书：主音量 0.6、BGM 0.35、音效 0.5；淡入 800 ms、交叉淡化 800 ms、
淡出 500 ms；同曲切页不重启。首次进入的淡入由播放器完成，循环中不重复淡入。
缺失素材时静默回退。首版没有角色配音。
