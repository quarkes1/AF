# AF 前端基础素材

本目录保存实际可加载的资源，不保存整张 UI 参考图、临时脚本或中间截图。
布局、交互和视觉要求仍以唯一设计规格书为准；本文件只说明资源清单和接入。

## 资源入口

`registry.json` 是统一资源索引。路径相对本目录，记录稳定 ID、种类、文件、
SHA-256、来源、许可及状态。前端通过资源 ID 解析受控路径，不依赖开发机路径。
根目录 `.gitattributes` 固定 SVG／CSS／JSON 的 LF 换行，字体、图片和下载的许可证
按原始字节保存，防止不同系统检出时破坏资源哈希。

| 目录 | 本轮准备内容 | 状态 |
|---|---|---|
| `brand/` | 深字／反白两版透明矢量 Logo | 沿用已审核资源，文件未改动 |
| `characters/aurore/` | 六张透明全身立绘及原清单 | 沿用已审核资源，文件未改动 |
| `backgrounds/` | 三张原背景与四张四牌楼场景，共七张独立背景 | 七张均于 2026-10-27 审核通过 |
| `icons/` | 74 个统一线宽的矢量操作／导航／科目图标 | 资源已准备；不是 emoji 或图标字体 |
| `fonts/` | 思源黑体 SC VF 2.005、Inter 4.1 及 KaTeX 0.19.1 配套字体与样式 | 本地文件与许可齐备 |
| `audio/` | 六首 Suno BGM、五种操作音效、两段开屏名称朗读；另保留已否决谱例 | 已按用户选择登记；各曲许可与开屏随机朗读规则单独记录 |

`approved` 仅用于用户已经明确审核的资源；`ready` 表示准备完成，不冒称新增的
用户审核；`review` 是新美术／音频审核状态。原三张背景及其页面绑定已经用户确认；后续
新增背景在审核通过前不改变默认页面绑定，不能以有文件或已填 ID 为由将其视为
已经审核。参考图仍存 `docs/assets/`，不得铺底冒充控件。

## 背景与立绘

- `background.library-hall-day`：用于首页、学科／章节导航、存档及管理面板底层。
- `background.library-reading-room-day`：用于主线、章节学习及讨论的场景底层。
- `background.campus-courtyard-day`：用于首页继续故事卡的独立图像区域。
- 已审核的四牌楼可选场景，不改变前三张默认绑定：
  `background.sipailou-classroom-day`（教室）、
  `background.sipailou-teaching-corridor-day`（教学楼走廊意象）、
  `background.sipailou-auditorium-day`（大礼堂前）、
  `background.sipailou-plane-tree-avenue-day`（梧桐大道）。
- 新场景使用内置图像生成工具绘制，以已审核 AF 背景约束画风。教室、大礼堂与
  梧桐大道参考校方实景；走廊依据同校教学环境的门窗／材质绘制，不冒称某间建筑
  内部的精确复原。参考网页、图片 URL、源图哈希及完整生成提示词记入 provenance。
  实景照片仅作绘制参考，不随应用素材分发。
- 背景只包含环境；人物、Logo、按钮、面板、标题和对白由各自资源／真实控件叠加。
- Aurore 继续采用原六张素材与 `bottom-center` 锚点，允许舞台裁切上半身；不得改服装、
  重绘或更改原 poseId。卡片缩略图使用真实运行截图，不能用新背景冒充真实存档。
- 背景来源及生成说明在 `backgrounds/provenance.json`，不会写入本机绝对路径。

## 字体与图标

- UI 导入 `fonts/fonts.css`，中文采用思源黑体，拉丁／数字采用 Inter。
  正文、控件、标题分别使用 400／500／700，字体和页面准备完再做视觉对照。
- KaTeX 的配套版本固定为 0.19.1；数学接入时使用同版本引擎和原版样式／字体，
  不将 UI 字体替换进公式。实际数学引擎接入属于后续前端工作，本轮只准备资源。
- 字体来源及原始哈希在 `fonts/sources.json`。KaTeX 样式是 MIT，字体二进制内嵌
  许可证为 OFL-1.1，两类许可分别保存，见根目录 `THIRD_PARTY_NOTICES.md`。
- 图标采用 24×24 viewBox、1.6 线宽、圆端点和 `currentColor`。使用内联 SVG 或 CSS
  mask；外部 `<img>` 不会继承父元素的 currentColor，不能误以为修改文字色就会改图标色。
  实际按钮命中区和缩放仍按规格书实现。
- 空卡片、空资料、状态提示可使用已准备的文件／文件夹／信息图标和真实文字；
  不需要单独生成带文字的占位插画。公式和图表不从参考图中裁剪作运行内容。

## 音频交接

音频由项目负责人选择，接入位置是 `audio/bgm/` 与 `audio/sfx/`，统一在
`audio/manifest.json` 记录文件、来源／许可、哈希、时长及经过检查的循环点。
六首 Suno BGM 已确认：前两首为免费账户主页曲，新增四首为付费订阅期间生成，许可分开记录。两段 CosyVoice 2 品牌名称朗读在 `audio/brand/`，每次启动等概率随机选择一版播放。具体来源与命名见音频说明，不把外部服务输出自动视作 MIT。三种 BGM 用途允许复用同一文件；同曲切页不重启。音效只用于用户按钮操作和手动
对白补全／推进，不为悬停、逐字字幕、自动推进或程序状态更新播放。没有音频时
保持静默，不创建空白音频、占位蜂鸣或角色配音。

本轮只准备素材。实际资源解析、页面、音频播放、字体等待及异常回退仍按规格开发和验收。
