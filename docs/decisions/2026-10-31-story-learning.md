# 日常主线与章节学习接入记录

本记录说明 v1.3 规格下本次实现与验证边界，不改变唯一规格源及 PDF，不作为另一份产品规格。对应 F03–F06、F08 的当前接入范围，以及 F11／F15 已有基础；不表示这些任务的全部扩展条目已经完成。

## 已接通的用户流程

普通桌面启动 → 配置模型 → 创建／激活真实存档 → 准备日常主线 → 呈现、推进、插话或选择 → 进入真实课程目录 → 教材设置或跳过 → 生成来源支撑的章节 → 阅读、讨论、作答及复核 → 返回主线 → 保存与重启恢复。

首页聊天、剧情编写、章节编写、题目核验／解答与资料分类分别使用新建的原生 dsh 会话。它们通过应用服务、冻结来源和事件投影协作，不共享一份宿主聊天记录。普通生产入口不注入离线测试回复。

## 数据与命令

日常主线、学习、任务、冻结产物、回执、作答及保存点通过主进程服务读写既有 `story.sqlite`。新增 `experience_records` 以存档外键绑定，删除存档时级联清除对应记录；各类记录分 kind 保存。资料数据库不被学习模块直接读取，通过资料服务提供版本化来源快照。

- `story.prepare/interrupt/advance/choose/resume/buffer.status/page.get` 管理生成与演出；`story.present` 的 story／learning channel 只确认实际呈现的前缀。
- `learning.enter/get/resume/discuss/submit/hint/review/return` 管理学习。`learning.resume` 可携带严格白名单的可选 `viewState`，持久保存已有规格要求的页签、草稿、题目位置及讨论锚点；该兼容扩展不允许客户端修改题目、评分或来源。
- `jobs.get/cancel/retry` 使用独立作业版本；相同业务幂等键返回原接受结果，失败重试保留原输入／作答，最多三次尝试，不清零父预算。
- `save.checkpoint/checkpoints/replay` 保存与只读浏览已经呈现的进度。旧点恢复和分叉没有伪装成已实现。

主进程复核 save／branch、活动档、目标 ID、聚合版本、contextRevision、profileVersion、模型配置及运行代次。全局姓名变更保留历史姓名，旧未播放尾部在下次进入时重建；仅打开／关闭面板不新增真实用户输入。关闭学习页后不会因切档而偷偷在新档进入旧章节。

## 会话与工具适配

直接复用已固定版本的 dsh 原生 Session、Agent、AgentLoop、Tool、Skill 与 DeepSeek 适配，不要求用户安装独立 dsh。每次操作新建执行会话，受限上下文来自 AF 投影；宿主日志不是产品记忆真源。

| 任务 | 可见上下文 | 应用工具／校验 |
|---|---|---|
| 首页角色聊天 | 当前档角色与身份、全局称呼、实际呈现近史 | `get_character_profile`、`recall_shared_history` |
| 剧情编写 | 冻结角色、双方身份、已呈现历史、当前用户输入、当前有效草稿前缀 | `get_task_context`、有限资源白名单、结构／交互／排版校验 |
| 章节编写 | 当前章节来源快照、目录与覆盖信息；无私密关系历史 | `source_retrieve`、`math_validate/math_render/layout_check/view_preview` |
| 核验／批改／讨论 | 本次问题、冻结题目与 rubric（仅相应核验任务）、授权来源及已呈现讨论 | 同一来源／数学／排版工具集、独立核验与确定性客观判分 |

正式 Skill 位于 `assets/skills/` 并登记内容哈希。来源工具只返回冻结授权版本的受限片段，显式报告截断；数学与预览工具只读，不提交角色经历。预览产物写入用户数据缓存，模型取得不含系统路径的引用。

普通剧情没有任意文件读取、shell、网络下载或平台消息工具。专业服务不会取得角色私密关系和完整聊天历史；显示第三者解答不意味着角色原本知道答案。

每个执行会话另有可执行的工具额度：来源读取最多三次、上下文读取一次、数学检查两次、预览与诊断别名合计三次；额度耗尽后从原生工具注册表撤下相应能力，返回剩余额度和真实缺口，不依赖提示词劝阻重复调用。这些操作仍计入父任务十二次模型请求及 token 门控，不通过子会话清零。结构修复仅返回有限 schema 字段诊断，不把剧情结束字段混入学习／研究格式。

题目锚点讨论由服务记录辅助；一般讨论还会对已经呈现的同一回答累计检查冻结参考要点，跨页的未读部分不参与。该匹配覆盖明确选项、带单位数值和完整参考短语，不声称能识别任意改写或暗示；此边界不能作为严格考试防作弊结论。

## 验证证据及限制

自动回归使用真实 Electron、SQLite、IPC、资源、字体及渲染组件。需要可重复生成内容的端到端用例，在忽略目录复制独立测试应用，仅替换复制目录中的模型工作器；生产构建不被改写。它们证明状态、交互与恢复，不证明真实模型教学质量。

真实 DeepSeek 联调另行验证首页多回合、完整幕／交互边界，以及本地 PDF、旧 PPT、PPTX 的资料解析与章节生成。题目经独立复核后才发布；不合格题目被拦截。实际材料中存在乱码 PDF、课件公式丢失和取材截断，均须保留警示，不能将“生成成功”解释为该教材被完整可靠教授。

报告和截图位于忽略的 `build/reports/`，私人材料位于忽略的 `localtest/`，实际 Key 仅由本地配置提供。原件、私人来源内容、Key、临时脚本及模型原始回复不进入提交。规范 Markdown 与 PDF 不改动。

本次不能声明完成的规格范围：

- 旧点覆盖恢复／派生分支及完整故事包导出。
- 长期记忆编辑、摘要压缩、角色成长／心情和平台连接。
- 一般符号代数证明、受控图表生成及任意复杂教材的可靠公式转录。当前数学检查以有限数值／单位为边界，其他原式明确尚未独立核验。
- 完整多层任务调度 UI、可交互预算调整及所有通用 MCP 工具／事件接口。当前使用相应功能的受限工具与轮询任务状态。
- 全部六类叙事节点和角色自主研究的完整编排；当前演出支持对白、旁白／行动文字及选择，章节来源在独立学习面板展示。
- 任意平台的安装包、干净机器与长期真人教学效果验收。

这些缺项没有通过静态回复、虚构连接或假成功提示代替；当前交付用于联合验收已接通的主线与学习流程，不能据此给全部 F03–F15 或 CT01–CT18 标记完成。
