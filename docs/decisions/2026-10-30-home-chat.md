# 首页真实聊天接入记录

依据：冻结规格 v1.3 第 15.17、17.11、24、25.3.1、25.4.1 节及 UI-HOME-CHAT-01。该记录说明本轮实现与证据，不修改规格源或 PDF，也不宣称完整 H03、R01、角色成长或主线演出已经完成。

## 运行边界

主进程 HomeChatService 接受类型化 `af:story` 请求，HomeRepository 与故事服务共用领域内的 `story.sqlite`。新增表使用独立 `home_` 前缀，保存已接受输入、任务、上下文快照、不可变回复片段、呈现回执及领域事件；删除存档同时级联删除这些数据。renderer 不直接访问数据库、文件或凭据。

角色任务使用随 AF 编译的 `character-agent` 子进程及 dsh 0.2.1-rc.3 的 AgentLoop、Session、ToolRuntime、SkillRegistry。每次调用新建原生会话；失败重试也生成新 job、task 与 session，不恢复模型原始日志。用户无需安装 dsh 或独立宿主。

角色只可调用两个只读工具：`get_character_profile` 返回当前存档冻结人设、立绘标签与用户称呼；`recall_shared_history` 检索当前分支经过呈现确认的有限历史快照。没有资料管理、任意文件、浏览器、Shell、外部平台或写状态工具。资料整理继续使用自己的会话与 Skill；两类任务共享最多两个模型执行槽，排队中的角色前台任务优先。

Skill 实体位于 `assets/skills/character-dialogue/1.0.0/` 并登记版本、哈希及能力。模型配置由现有系统加密服务提供，仅在 main 与本次工作器间传递；不进入上下文、IPC 公共响应或历史。默认沿用用户配置的 DeepSeek／兼容服务。

## 命令、事务与恢复

- `story.send`：原输入、接受事件、上下文版本、Job 及 ContextBundle 在同一事务写入；相同幂等键返回原结果。明确点击发送属于新输入，重试按钮复用原输入。
- `jobs.get/cancel/retry`：读取、显式取消与显式重试。重试最多三次尝试总量，不能越过已更改的上下文或用户档案版本；原输入不重复记账。
- `story.present`：保存片段标识、版本及最大已呈现字素前缀，回执去重；后一个片段不能先于前一个片段完成。未显示文字不进入共同经历。
- `story.history`：读取当前分支的已接受输入与已呈现回复；支持有限数量及向前序号过滤。
- `home.get/home.stop`：供首页使用的当前任务／候选回复投影与停止显示命令，不替代后续完整 Playback／剧本契约。
- `profile.get/update`：独立版本的全局用户档案；姓名默认“我”，限制为 1–32 个字素。人物身份不推导为用户姓名。已接受的旧消息保留其当时姓名。

取消通过 AbortSignal 终止当前工作器。存档、分支、contextRevision、profileVersion、providerFingerprint 与 runtimeEpoch 共同隔离过时任务。切换存档或搭档、删除存档、更改姓名及模型配置会阻止对应旧任务继续提交。启动后原先未终结的任务标为中断失败，只允许用户明确重试，不自动消耗模型额度。

ContextBundle 保存内容哈希、当前输入事件、来源事件列表与可见序号截止点；不含未播放草稿、上传资料、其他存档或角色资源二进制。近史及只读回忆均有大小上限。每次尝试最多 12 次模型调用，采用 48,000 token 的后续调用停止阈值，并受工作器超时和输出长度校验限制；最后一笔已发生请求可能跨过阈值，不能将其视为费用硬上限。这是当前首页回合的有限预算；通用父任务账本、跨重试精确费用结算与持久化全局调度仍是后续工作。

## 呈现与交互

沿用审核通过的左下聊天栏和立绘视差布局。模型先生成完整且通过 schema 校验的有限回复，再播放字幕；不是将网络原始增量直接写进历史。对白默认每秒 4 个字素，可随设置调整为 3–5；旁白和关闭逐字效果时完整显示。选中的有效立绘标签可随实际呈现片段切换，未知标签回退默认立绘。

呈现确认由连续绘制帧与滚动视窗内的文字范围共同约束。关闭面板、页面被遮挡或窗口不可见时暂停字幕及回执；向上翻阅历史时暂停跟随。长篇全文展示保留未读开头，实际滚动读到的连续前缀才可计入历史。停止显示保留已呈现内容，隐藏剩余候选文字。

提交前先冲刷已显示前缀；切换存档、修改全局姓名前也执行同样操作。旧上下文封存后丢弃失效锚点，避免下一次发送被旧页阻塞。失败保留原消息并允许明确重试；未发送草稿按存档／分支分开，仅在当前挂载期间保存。缺少模型配置时不接受发送，提供设置入口。
