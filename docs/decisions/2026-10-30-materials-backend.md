# 资料管理后端实现记录

日期：2026-10-30。基线：设计规格书 v1.3 第5、17.4–5、17.11–12、19、25章；实现覆盖资料管理所需的基础持久化、解析、分类、教材与来源服务。本记录用于说明实际实现及边界，不替代冻结的规格源或 PDF。

## 数据与执行边界

- 桌面副本、SQLite、解析快照和工作缓存位于 Electron userData。renderer 通过 preload 白名单命令访问，不直接访问文件、数据库或凭据。
- 文档按内容指纹去重；原件不移动、不覆盖。逻辑移除、可选删除受管副本和保留已引用证据分开处理。旧解析块与教材映射版本保留，当前检索只使用活动内容。
- 主进程保存持久任务、幂等回执和版本。同步领域写入与回执同事务提交。进程重启将未完成任务记为中断，用户明确重试，不自动重放收费调用。
- Windows Office 转换和 OCR 的固定下载来源、版本、SHA-256 见 config/document-runtime.json；准备工具是 scripts/prepare-document-runtime.mjs。构建携带受管组件及许可，依赖缺失按 AF 安装完整性错误报告。
- 每个模型作业使用独立进程和全新 dsh 会话；只有当前授权文档读取和课程目录工具。解析并发2、模型作业并发2；取消只影响所属任务，迟到结果不能覆盖用户手动归类。
- 服务地址、模型和 Key 一起由系统加密后存入 SQLite；命令中的 Key／密码只进入执行内存。敏感参数参与受保护密钥生成的 HMAC 幂等摘要，不以明文或普通口令哈希保存。公开接口不回传 Key。

## 已确认的分类行为

分类采用两个隔离的模型阶段：先只读本次资料，按实际内容自由生成类别、资料类型、主题和摘要；再结合已有类别、别名和代表资料的内容范围归并。类别名不硬编码，单份资料可创建新类别，论文可使用研究主题类别，不要求先确认课程名称。自动归类必须引用本次文件内有效内容块；确实无法判断时进入需核对状态。手动输入新名称先检查相似科目，用户可采用已有名称并登记别名，或明确保留独立科目。数学分析与高等数学不被硬编码为全局同义词。

手动调整是持久覆盖；重扫和资料改版保留该决定。明确重新自动归类才解除覆盖。源文件更新与另一已有文档内容相同时复用其资源身份，保留已有用户编辑，不覆盖其名称或科目。一份文档可关联多个科目。

## 教材与来源

教材候选的书名、版次、作者、出版社、ISBN 与来源证据分开保存，缺少原文支持的字段不按已知事实展示。最多三轮短问答；跳过后使用有明确依据的推定或通用框架。教材识别只读请求指定的资料范围，不携带其他课程、角色私聊、记忆或剧情。联网教材元数据查询尚未启用，不下载教材全文。

SQLite FTS 保留中文预处理与来源锚点。检索可定位当前文件页／段落；历史引用的块保留。资料解析或后台分类不是角色经历，也不是用户已掌握的学习证据。

## 验证和交付边界

可复现的长期测试位于 tests/unit/material-*.test.ts、tests/e2e/material-backend.spec.ts 及已有资料/PDF/设置测试。固定合成样本验证DOC、DOCX、PPT、PPTX、PDF、MD、TXT，以及中英文扫描PDF OCR；实际 DeepSeek 调用验证同科目归并和别名确认。临时诊断与真实 Key 联调脚本只留在被忽略目录，不随仓库交付。

本次不宣称完成真实剧情/存档/教学生成、任意复杂文档的无损还原、公式数学正确性、所有旧版 Office 加密方式，或干净机器安装包验收。公式与低质量OCR保留原图核对，未知状态如实显示。最终验证数量及命令结果见本地 build/reports 下记录，不能以测试数量代替规格逐项验收。

## 两阶段分类调整与验收

依据用户对电路课件与脑机接口综述的实际反馈调整，取代原先“先看已有科目”的分类策略。资料类型与狭义主题独立保存，避免把章节名或“论文／实验报告”等文体当作科目。初分阶段不提供课程目录工具；归并阶段重新创建 dsh 会话，只继承通过结构与来源验证的提案，不继承上一阶段对话。界面在原有归类依据中显示内容摘要与资料类型。

每个处理窗口最多三份资料，后续窗口使用已提交的类别目录。类别目录工具按名字、别名及内容主题搜索，可按 ID 和游标读取；默认五条，单条代表摘要限长，响应限制约 10KB，不再整体注入全部类别和摘要。完整目录仍受本机服务管理，分页不会赋予模型任意文件读取权限。

同名／别名优先复用必须由第二阶段明确引用已有 ID；新类别撞名会拒绝并最多修正一次，不静默改成复用。提交前检查授权、完整覆盖、重复文件、分离约束和资料版本，事务中先固定所有新类别 ID，再登记别名，防止同轮别名占用另一新类别名。类别替换继承原类别的分离边界，防止下一窗口或下一次导入绕过。原有类别不会因归并被自动删除或重命名；人工归属、明确分离和教材历史保留。

官方 DeepSeek 请求使用其 [JSON Output 模式](https://api-docs.deepseek.com/guides/json_mode/)；其他兼容厂商保持兼容请求。无效 JSON 在原会话预算内最多修正一次，归并结构／引用失败最多另起一次修正阶段，仍失败则如实报告，不无限重试、不伪造成功。一个大任务的已提交窗口保留，出错窗口不部分提交。

新增回归覆盖单份电路课件、主题型综述、跨批次同义归并、并发导入、人工编辑、取消、无效输出、低质量证据、跨窗口分离边界、同轮别名冲突、旧摘要失效及大目录分页。126 项单元测试、3 项资料后端 Electron 回归、类型检查和生产构建通过。真实 DeepSeek 使用六份合成资料完成单份电路、混合论文／实验／数学资料及后续数分练习归并，未强制固定模型生成的名称。该验证不等同于已复现用户全部原始课件的每种版式；实际文件仍需人工验收。

合并前复验：126 项单元测试、10 项相关 Electron 回归、类型检查、生产构建、179 项资源校验与依赖边界检查通过，生产依赖审计为 0 个已知漏洞。Git 索引中的 Skill 原始字节与清单哈希一致，许可证按原始字节保留；凭据、个人绝对路径、临时文件、下载组件及未通过音频均未加入提交。
