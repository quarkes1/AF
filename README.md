全部有效界面参考图、立绘及样式说明集中在规格书第 23 章。后续开发必须同时遵守相应图版、交互说明、工程结构与验收契约。

`assets/` 保存正式运行素材，`docs/assets/` 保存规格书引用的参考图和数学示例。六张 Aurore 全身立绘及清单位于 `assets/characters/aurore/`，透明矢量标志位于 `assets/brand/`。

工程目录以规格书第 17.12 节为准：`src/`、`tests/`、`scripts/`、`config/` 为后续实现预留，`build/` 与 `tmp/` 用于可重建产物和临时文件。旧实现与历史交付文件已从当前工作目录清除，历史通过 Git 查询。变更按规格书第 22 节执行，不并列维护另一份有效规格。
