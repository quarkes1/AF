# Aurora Forge / AF

在互动中自然学习。

Aurora Forge 是以视觉小说呈现日常互动与章节学习的桌面应用，使用 Electron、electron-vite、React 和 TypeScript。设计基线为 v1.3，当前前端框架包含开屏、标题栏、首页、存档、章节学习、搭档档案、设置与资料管理；完整学习平台仍在开发中。

## 当前可用

- 黑屏 → AF 品牌淡入与随机一段品牌朗读 → 品牌淡出 → 校园标题栏。
- 标题栏根据本地时间显示白天（06:00–17:00）、黄昏（17:00–19:00）和夜景，包含分层树冠、云层与水面动画；夜景顶部窗户保持熄灯。
- 标题栏点击或按键进入首页，播放一次确认音效。标题栏至首页共约 2 秒过渡，BGM 保持同一播放实例，不重启。
- 首页使用已审核的 Aurore 立绘与布局，人物、导航有鼠标视差，控件有悬停和按下反馈。
- 点击立绘展开左下聊天栏，底边固定、由下向上展开、由上向下收起；支持草稿保留、输入法保护、Enter 发送与 Esc 收起。无存档时发送引导创建故事；桌面端已接入真实故事创建。已有活动档时明确提示聊天服务尚未接入，草稿不会发给模型。
- 存档入口打开已审核布局的故事列表与右侧详情；支持选择、分页、故事／保存点分层和手动／自动／快速过滤。桌面端支持真实创建、激活、重命名、删除及重启恢复，演示模式继续隔离使用预览数据。
- 章节学习入口提供学科总览、课程搜索、章节地图与文本目录；演示模式可进入搭档在场的学习演出，切换教材／黑板／练习，保留讨论草稿与示例练习选择。公式使用本地 KaTeX 排版。
- 设置入口提供六个横排分类索引与连续滚动内容，支持显示、音量、字幕和姓名等本地偏好调整。
- 搭档档案提供可横向滚动的搭档库、详情与编辑页面，支持自定义搭档、立绘标签和首页搭档选择；桌面端模板、版本与选择持久保存，旧存档保留独立角色快照。
- 首页背景选择与音乐播放器支持切换背景、选曲、播放／暂停和拖动进度，保持已审核的切角面板与鼠标视差。新增六张已审核的南京／校园场景插画，秦淮河采用低饱和度拱桥视角版本。
- 资料管理提供学习文件与应用资源两类入口，支持实际文件导入、真实内容预览、手动分类、自定义背景／BGM、首页联动与本地持久保存。
- 支持开屏跳过、静音、简化动效、素材缺失降级，以及本地前端预览偏好保存。

资料管理已有主进程 SQLite、解析工作器与隔离的 dsh 模型任务。搭档模板与故事元数据也已由独立的主进程 SQLite 服务保存。首页真实模型回复、主线剧本、检查点／回看／分叉、完整故事包导出、教学内容生成、学习证据持久化及其他角色／平台 MCP 调度尚未实现；聊天草稿与学习界面状态仍只在本次挂载期间保留，不代表共同经历。页面预览不代表这些功能已完成。当前没有安装包或干净机器验收结论。

## 本地运行

开发环境使用 Node.js 24 或更高版本与 npm，首次安装需要联网下载依赖及 Electron。

```powershell
npm ci
npm run runtime:documents
npm run dev
```

编译后运行桌面预览：

```powershell
npm run build
npm run preview
```

`preview` 使用已有编译产物；修改源码后需要重新构建。桌面运行前请关闭之前的 AF 窗口，避免单实例机制切回旧窗口。

固定时段检查标题栏（开发预览，不改变系统时间）：

```powershell
npm run title:review -- day
npm run title:review -- dusk
npm run title:review -- night
```

不指定时段时按本地时间选择。浏览器辅助预览使用 `npm run dev:browser`，地址为终端显示的本地地址；浏览器可能限制音频自动播放，音频验收以 Electron 为准。

存档页演示预览：

```powershell
npm run save:review
```

进入首页后点击“存档”。此模式明确标记演示数据，用于检查满列表、分页、缺图、损坏、迁移及保存点界面。列表展示全部搭档的存档，以最后修改时间降序排列；重命名会更新时间并移至前面。重命名和删除仅修改本次内存数据，重启即复原。卡片高亮不改变搭档；“继续故事／读取此处”先恢复该存档关联的搭档快照，缺少关联或资源不可用时保持原选择。此演示模式不读写真实故事；普通桌面启动可创建和管理真实故事元数据及角色快照，剧情播放、回看、分叉与完整故事导出仍待后续模块。普通启动不载入演示存档。

章节学习演示预览：

```powershell
npm run learning:review
```

从首页点击“章节学习”，在学科总览选择高等数学并进入章节，选择“第二章 导数与微分 / 2.1 导数的概念”，再点击“继续学习”查看教材、黑板和练习。课程、目录与正文均明确标记为演示；切换科目保留各自地图选择与缩放，退出后可恢复本次讨论草稿和示例作答。普通启动没有资料时只显示添加入口，不生成虚构课程。

讨论不产生虚构 AI 回复，“就这段讨论”保留引用片段与来源标签；“我来解释”打开用户输入，示例解析需要单独点击查看。例题反馈由固定样例演示，不写入成绩、关系或记忆。LaTeX 解析采用禁用外部资源和宏定义的本地排版，排版成功不代表已完成数学语义核验。

搭档档案预览：

```powershell
npm run companion:review
```

首页“搭档档案”进入搭档库，再打开详情或编辑。卡片仅显示姓名与属性，鼠标滚轮可横向浏览；此命令额外加载七个明确的自设草稿，用于验证较多角色时的滚动。普通启动只提供 Aurore 与新建入口。详情按钮为“选中／已选中”，选中后首页显示该搭档的默认立绘、姓名和聊天提示；聊天草稿按搭档稳定 ID 分开保存。预置搭档编辑时创建副本；创建、草稿、编辑、删除和当前搭档选择仅作用于本次内存，可导入／导出 JSON 预览包，不写入真实故事或记忆。通用界面使用搭档名字或“TA”，不假设性别。新故事服务尚未接入。

外观资源支持自定义立绘标签，默认六个名称均可修改，也可继续添加或删除；使用稳定标识关联图片，改名不丢失资源。可以指定任意已上传图片作为默认立绘，用于首页、搭档库、档案展示和缺图回退。单张 PNG 不超过 5MB，预览包合计不超过 64MB；新版包保留全部标签、图片和默认选择，并兼容旧版六立绘预览包。

首页故事卡片根据最近修改的存档显示“继续故事”、章节名和最后一句话的前十五字，超出追加 `...`；无存档或缺少对白时显示“与你的日常，\n就是奇迹”。点击继续会定位并恢复该存档的搭档；真实剧情播放仍待接入。

首页右下角为背景和音乐两个透明图标按钮。背景选择器向左展开七张已审核缩略图，不显示图片名称，横向滚动，选择时大厅虚化；点击缩略图后应用并收起。音乐选择器在主控件下方的有限区域纵向滚动，保留两首主页曲原名“新しい朝の光”“君と紡ぐ日々”。选择会被记住，当前曲目不重复启动，新曲成功播放后淡入淡出，失败保留原曲；初始播放失败可通过点击曲目重试。全部滚动条隐藏端部箭头。主页 BGM 整曲循环，标题栏进入首页时继续同一播放器。首页及已接入页面的按钮统一播放操作音效，默认合成音量为 42%，可在设置中调整，静音时不播放。

设置页预览：普通启动后点击首页右上角“设置”。六个分区连续排列，顶部索引平滑定位并跟随滚动高亮；小窗口中索引可横向滚动。音量、静音、失焦衰减、字号、简化动画、逐字字幕与字幕速度即时应用，姓名在失焦或 Enter 时提交；这些前端偏好会本地保存，重开保留。默认使用完整动画，简化模式仅在用户主动选择后启用，不由系统偏好自动开启。自动测试使用独立临时配置目录，不覆盖日常预览偏好。F11 切换全屏。

从设置打开搭档档案或存档页后返回原设置位置和入口焦点。模型设置支持 DeepSeek（默认 deepseek-flash）及其他兼容服务，主进程通过系统加密保存整份服务配置；可测试连接、替换或移除 Key。外部连接、主动互动、全库备份与完整诊断服务仍未接入，不展示虚构连接、容量或费用。

## 验证

```powershell
npm run typecheck
npm test
npm run check:assets
npm run check:boundaries
npm run build
npm run test:e2e
npm run test:title-review
```

`test:e2e` 需要先构建，并在真实 Electron 中检查启动、交互、素材与短音效播放；`test:title-review` 自行构建并检查时段切换、动画分层和背景加载失败降级。两类端到端命令应顺序运行，避免同时改写构建产物。测试报告与截图统一写入 `build/reports/`，不提交仓库。

自动测试只覆盖当前实现，不能替代视觉审核、完整规格验收或干净机器安装包验收。

## 目录与素材

| 目录 | 用途 |
|---|---|
| `src/main/`、`src/preload/`、`src/renderer/` | Electron 主进程、隔离桥与前端 |
| `assets/` | 已确认运行素材、来源和资源清单 |
| `docs/` | 唯一规格源、PDF 与正式参考图 |
| `config/`、`scripts/` | 配置与长期维护的工程工具 |
| `tests/` | 单元与 Electron 端到端测试 |
| `build/`、`tmp/` | 已忽略的构建产物、报告及临时文件 |

六张 Aurore 透明全身立绘位于 `assets/characters/aurore/`，透明矢量标志位于 `assets/brand/`。素材由 `assets/registry.json` 校验，开发服务器只提供登记的可用资源，构建只复制已确认资源。已否决的三首程序 BGM 及谱面仅保留本地副本并受 Git 忽略，仓库保留拒绝记录，禁止接入播放。

音频的来源与使用范围见 [音频说明](assets/audio/README.md)。用户审核的六首 BGM、五种操作音效和两段品牌朗读分别保留来源与许可记录；它们不因项目许可而自动获得重新授权。

`scripts/docs/` 为本地文档辅助目录，按 `.gitignore` 忽略，不随仓库分发。临时脚本、报告、缓存和构建产物不得提交。规格变更按第 22 节维护同一 Markdown 与同版本 PDF，不并列维护竞争性规格。

主页音乐播放器：采用已确认的 UI-HOME-MUSIC-PLAYER-01 布局，左侧支持上一首、暂停／续播、下一首和真实播放进度拖动，右侧为上下滚动的原名曲目列表。列表不显示行首音符；播放器面板与大厅控件一起参与鼠标视差，打开、收起、悬停和按下均保留过渡。

## 应用图标

应用图标使用已确认的 Aurore SD 头像（眨眼、脸侧剪刀手及抬肘姿势）。正式原图、多尺寸 Windows ICO、窗口 PNG 和浏览器 favicon 位于 `assets/brand/app-icon/`，来源与哈希记录在同目录清单。窗口和浏览器预览已接入；开屏及界面内的 AF 字标继续沿用原版本。

`npm run assets:icons` 可从已确认原图重新生成 PNG／ICO，不重新绘制或裁切。当前尚无安装包打包流程；后续打包必须使用 `assets/brand/app-icon/aurore.ico` 作为 Windows 可执行文件及快捷方式图标。

## 资料管理与自定义资源

从首页进入“资料管理”，顶部切换“学习资料／应用资源”。选择条目后右侧详情展开，左侧分类和中间内容同步稍向左移；参考图为 `docs/assets/af-ui-v08/` 中两张已确认图版。

- 学习资料：支持选择文件、选择文件夹后确认一次性导入；保存文件副本，原文件不移动、不覆盖。按内容指纹去重，支持搜索、手动科目／教材／章节信息、重命名、移除副本和下载原件。大文件／大批次先确认；可取消尚未处理的文件，已导入内容保留。失败项目逐项说明。
- PDF 使用本地 PDF.js 工作器显示原始页面，支持翻页和临时密码输入；所需 CMap、标准字体及许可证随构建分发，不依赖 CDN。DOCX／PPTX 从实际文档提取正文和内嵌图片，PPTX 按保存的幻灯片关系顺序预览；提供实际内容浏览，不复原 Office 原始版式。TXT／MD 显示原始文本，支持编码选择，不执行脚本。
- DOC／PPT 由 AF 管理的 LibreOffice 转为结构化格式；PDF 提取文本及原始页图，扫描页使用本地中英文 OCR，低质量结果保留核对标记。后台解析并发为 2，可取消与重试，单个文件失败不回滚整个批次；文档密码只用于本次解析。“已解析”表示可检索，不代表已完成教学内容生成或学习。
- 应用资源分为 Illustration 和 Music。Illustration 展示全部已确认场景插画，排除人物立绘和云层图层，缩略图不显示名称及来源标签，名称仅在详情中显示，Music 展示全部已确认曲目（不包含音效和品牌朗读）；自定义插画及音乐可用于首页。支持导入 PNG／JPEG／WebP 插画、MP3／WAV／OGG／FLAC／M4A 音乐，实际解码检查尺寸或时长；编码是否可播放以当前运行时检测结果为准。背景可以调整横向位置并在真实首页预览，音乐可试听和设为主页 BGM。可作首页背景的插画与全部音乐加入首页选择器。内置资源保留，只允许移除自定义项；移除当前使用项前先切换内置资源。
- 桌面端使用主进程 SQLite 和 userData 内的受管副本；旧 IndexedDB 资料在后端写入成功后迁移，并迁移当前背景／音乐选择。浏览器辅助预览仍使用 IndexedDB，不提供主进程模型与转换能力。清除应用数据会移除本地资料，请先导出需要的原件。
- 配置模型后，导入完成会先由独立会话按内容自由生成类别、摘要、资料类型和主题，再由另一独立会话结合已有类别的内容范围归并；类别名不硬编码，单份资料也能新建，无法确认课程名的论文可按研究主题整理。类别目录按需检索和分页读取，避免全部塞入上下文。单个文档手动输入新名称时检查相似科目，可采用已有名称并登记别名，也可明确保留独立科目。手动归类不会被后台重扫覆盖，一份文档可关联多个科目；用户明确分离的类别在跨批次整理后也保留边界。既有资料可点击“自动整理科目”重新整理，手动指定的条目默认跳过。
- 自动整理仅向所配置模型发送本次授权文件的必要文本片段、文件名和科目目录；不会发送原始二进制文件、搭档私聊、其他剧情或记忆。每个模型任务使用新会话，只开放当前资料读取与科目目录工具，复用 dsh agent-loop 和 Skill 注册，不提供任意 shell／文件系统工具。任务有调用预算、超时、取消和版本校验。
- 教材识别保留来源依据，最多三轮问答，可不知道／跳过并使用通用框架；候选、系统推定与用户确认分开。教材映射版本和旧内容块快照保留，重新解析不破坏旧锚点。SQLite FTS 检索结果可定位来源。
- “关联文件夹与增量扫描”支持原生授权目录、确认导入、重扫与每 15 秒自动检查；仅处理新增／改版，原件只读。改版保留旧副本并继承手动分类；若与已有另一文档内容相同，保留已有文档的手动信息。解除关联取消该来源尚未完成的扫描／导入，退出 AF 后停止监视。普通“选择文件夹”仍提供一次性文件批次导入。
- 默认移除列表关联，不删除原件；可另外请求删除未被证据引用的受管副本。重新导入会补回缺失的副本，教材证据引用的历史快照保留。

PDF 预览固定内外滚动条空间，仅在有效宽度或像素比变化时重绘，使用版本标记丢弃过时任务；已有页面保留到新页面完成，避免高度与滚动条互相触发抖动。动态回归测试持续采样画布尺寸和重绘次数，覆盖首次打开及窗口缩放。

Windows 任务栏使用独立 AppUserModelID、完整重启命令／显示名称和稳定的 ICO 路径。图标按内容哈希保存到应用用户数据目录，避免引用会在构建时清除的临时文件；测试窗口使用独立身份，不影响正式窗口的任务栏分组。请完整退出旧预览后重启验收系统显示。未来打包仍需设置可执行文件／快捷方式图标。

### 资料模块的运行组件与验证边界

`npm run runtime:documents` 供源码开发准备 Windows x64 的 LibreOffice 26.2.6 及中英文 OCR 模型，约需下载 356 MiB 的 Office 组件和少量语言模型；先校验固定哈希，再解包到忽略的构建目录。构建将这些组件及 Skill 复制到 `build/compiled/resources/`，工作器使用 AF 自身的 Electron 运行时，不调用开发机全局 dsh、Node 或 Python。组件缺失时报告 AF 安装完整性错误，不把“请用户另装 Office”当成功路径。首次准备需要联网；组件来源和固定哈希见 `config/document-runtime.json`。

当前已验证七种格式的实际文本／结构提取、扫描 PDF 的中英文 OCR、SQLite 持久化、文档改版、分类别名、取消、幂等冲突、真实 DeepSeek 分类调用与 Electron 页面联动。公式转录仍需原图核对，普通文本 OCR 的高分不构成数学正确性的证明；尚未完成任意复杂版式、所有加密旧 Office 文件及干净机器安装包的发行验收。教材联网元数据检索没有启用，候选仅使用授权资料与用户回答；不会自动下载教材全文。

## 搭档模板与故事数据

桌面端“搭档档案”的创建、复制、编辑、导入、删除及选中由主进程保存到 userData 下的 story.sqlite。内置 Aurore 不可原地修改或删除，编辑会创建副本。自定义立绘仅允许已登记角色资源或通过实际解码检查的内嵌 PNG；模板包继续兼容已有导入导出格式，不包含故事经历或模型凭据。

在存档页点击“新建故事”，确认搭档、世界背景、双方身份与关系起点。创建保存模板版本及本档身份的独立快照；之后改模板或从库中删除模板，不改变已有故事。创建、卡片选中与激活分开：点卡片只查看，点“继续故事”才激活并切换首页搭档。首次打开默认选中活动档，之后保留列表选择；所有故事按最后修改时间降序显示，单纯激活不修改时间。已激活故事、模板选择和元数据在完整退出后恢复。

写命令由主进程生成稳定 ID，使用目标聚合版本和持久幂等回执；新建的 expectedStateVersion 为 null，模板与存档之间的无关修改不会互相制造版本冲突。删除须输入完整名称，仅影响目标对象。此基础服务尚无正在运行的角色模型任务，不宣称完成未来任务取消、经历回执、分叉与恢复协议。首页暂不生成模型回复；临时输入按搭档模板／存档分别隔离，切换不会自动发送或记入历史。
